📚 Conhecendo o Bootstrap

Entenda a tecnologia utilizada na criação da GameZone.

O que é Bootstrap?

Bootstrap é um framework front-end utilizado para facilitar a criação de sites e aplicações web. Ele oferece diversas classes, componentes e ferramentas prontas para criar interfaces organizadas, modernas e responsivas.

Para que serve?

O Bootstrap ajuda os desenvolvedores a criar páginas com mais rapidez e organização. Ele possui recursos para menus, botões, cards, alertas, formulários, grids e muito mais.

📐 Sistema de Grid

O sistema de Grid do Bootstrap permite organizar os elementos da página em linhas e colunas.

Alguns exemplos utilizados neste projeto:

  • container: organiza e limita o conteúdo da página.
  • row: cria uma linha para organizar as colunas.
  • col: cria uma coluna.
  • col-md: define o comportamento das colunas em telas médias.
  • col-lg: define o comportamento das colunas em telas grandes.

📱 Responsividade

Design responsivo é uma técnica que permite que um site se adapte a diferentes tamanhos de tela.

O Bootstrap facilita esse processo através de classes que permitem definir como os elementos devem aparecer em celulares, tablets e computadores.

📱 Celular → 1 coluna
📱 Tablet → 2 colunas
💻 Desktop → 3 colunas
